CryptoSafe 🔐

A simple file encryption and decryption web application built with Python and Flask.

About the Project

CryptoSafe is a Computer Science semester project designed to demonstrate file security using Fernet symmetric encryption. It provides a simple web interface where users can encrypt files, download encrypted files, and decrypt them using the correct encryption key.

Features

- Encrypt files using Fernet symmetric encryption.
- Generate encryption keys automatically.
- Download encrypted files.
- Decrypt files using the correct key.
- Simple and responsive web interface.
- File upload size limit of 16 MB.

Technologies Used

- Python
- Flask
- Cryptography (Fernet)
- HTML
- CSS
- JavaScript

Installation

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/CryptoSafe.git

Replace "YOUR-USERNAME" with your GitHub username.

2. Open the project folder

cd CryptoSafe

3. Install dependencies

pip install -r requirements.txt

4. Run the application

python app.py

5. Open in your browser

Visit:

http://127.0.0.1:5000

Important Note

Keep your encryption key safe. You need the correct key to decrypt your encrypted files. Losing the key may result in permanent loss of access to your encrypted data.
